Privacy Policy

Last updated: 2026-08-16

This is a personal site. It doesn't run ads and doesn't have a login, so there isn't much to collect — but here's exactly what happens when you visit.

Analytics

This site uses Google Analytics (GA4) to see aggregate traffic — which pages get read, and a handful of interaction events (button clicks, outbound link clicks, how far someone scrolls on a blog post). Google Analytics sets cookies to do this. No account registration, no personal profile, no data sold to anyone. See Google's privacy policy for how Google itself handles that data.

Contact links

Email links on this site open your own mail client — nothing you type gets submitted to or stored by this site.

Advertising

No ads run on this site today. If that changes in the future, this page will be updated first to say what's added and what it collects.

Hosting

This site is hosted on GitHub Pages, which may log standard request data (IP address, browser type) as part of serving the site — see GitHub's privacy statement.
